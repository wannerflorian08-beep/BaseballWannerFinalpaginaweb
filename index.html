Sobre el proyecto

Baseball Warner es un proyecto web desarrollado con HTML5 semántico, CSS3 y un catálogo dinámico generado a partir de un archivo XML transformado mediante XSLT. Explora las páginas del sitio para conocer más sobre el equipo, el catálogo de leyendas y cómo ponerte en contacto.
